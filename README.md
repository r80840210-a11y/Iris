# Telegram-бот для управления группами

Мощный бот для управления группами Telegram: удаляет спам-рекламу и защищает чат.

## Возможности

- Автоматически удаляет сообщения со спам-словами
- Предупреждение удаляется автоматически через 5 секунд, чтобы не засорять чат
- Приветствует новых участников
- Система одного администратора: управлять ботом могут только пользователи с указанными ID
- Ключевые слова хранятся постоянно и не теряются при перезапуске бота
- Массовое добавление ключевых слов для удобного управления
- Дружелюбный интерфейс с кнопкой добавления бота в группу

## Установка

1. Склонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Создайте бота через @BotFather и получите токен
4. Настройте переменные окружения (в файле `.env`):
   ```
   BOT_TOKEN=токен_вашего_бота
   ADMIN_IDS=123456789,987654321  # ID администраторов через запятую
   SPAM_KEYWORDS=казино,ставки,порно  # необязательно: начальные спам-слова
   ```

## Подключение к серверу DropGram

Бот по умолчанию работает с сервером DropGram, а не с `api.telegram.org`:

- адрес Bot API задаётся в `.env` строкой `API_URL=http://67.211.221.152:8888`
- в коде он подставляется в `Application.builder().base_url(...)` (суффикс `/bot` библиотека добавляет сама)
- токен нужно получать у @BotFather **внутри DropGram**, токены обычного Telegram на этом сервере не работают

## Развёртывание на Linux

### 1. Установка Python

Debian/Ubuntu:
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

CentOS/RHEL:
```bash
sudo yum install epel-release
sudo yum install python3 python3-pip
```

### 2. Создание каталога проекта

```bash
mkdir -p ~/telegram_bot
cd ~/telegram_bot
```

### 3. Виртуальное окружение (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Клонирование репозитория

```bash
git clone https://github.com/ваш_логин/telegram_group.git
cd telegram_group
```

Если Git не установлен:
```bash
# Debian/Ubuntu
sudo apt install git

# CentOS/RHEL
sudo yum install git
```

### 5. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 6. Настройка переменных окружения

Создайте файл `.env`:
```bash
nano .env
```

Добавьте необходимые настройки:
```
BOT_TOKEN=токен_вашего_бота
ADMIN_IDS=123456789,987654321
SPAM_KEYWORDS=казино,ставки,порно
API_URL=http://67.211.221.152:8888
```

Сохраните и выйдите (Ctrl+X, затем Y, затем Enter).

### 7. Запуск бота

```bash
python3 bot.py
```

### 8. Фоновый запуск и автозапуск

#### Через Screen:

Установка Screen:
```bash
# Debian/Ubuntu
sudo apt install screen

# CentOS/RHEL
sudo yum install screen
```

Создание новой сессии:
```bash
screen -S telegram_bot
```

Запуск бота внутри сессии:
```bash
cd ~/telegram_bot/telegram_group
source ../venv/bin/activate
python bot.py
```

Отключиться от сессии, оставив бота работать: `Ctrl+A`, затем `D`

Вернуться в сессию:
```bash
screen -r telegram_bot
```

#### Через Systemd (автозапуск при загрузке):

Создайте файл сервиса:
```bash
sudo nano /etc/systemd/system/telegram-bot.service
```

Содержимое:
```
[Unit]
Description=Telegram Group Management Bot
After=network.target

[Service]
User=ваш_пользователь
WorkingDirectory=/home/ваш_пользователь/telegram_bot/telegram_group
ExecStart=/home/ваш_пользователь/telegram_bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Включите и запустите сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
```

Проверка состояния:
```bash
sudo systemctl status telegram-bot
```

Просмотр логов:
```bash
sudo journalctl -u telegram-bot -f
```

## Использование

1. Запустите бота:
   ```
   python bot.py
   ```
2. Добавьте бота в вашу группу Telegram
3. Выдайте боту права администратора (право удалять сообщения)
4. Управляйте ботом командами:

### Основные команды (доступны всем)
- `/start` - запустить бота
- `/help` - показать справку

### Команды администратора (только для ID из `.env`)
- `/add_keyword ключевое_слово` - добавить одно спам-слово
- `/bulk_add_keywords слово1\nслово2` - массово добавить спам-слова, по одному в строке
- `/remove_keyword ключевое_слово` - удалить спам-слово
- `/list_keywords` - вывести все спам-слова
- `/list_admins` - вывести ID всех администраторов

## Хранение данных

- Ключевые слова хранятся в файле `keywords.json` и не теряются при перезапуске бота
- При добавлении или удалении ключевых слов данные сразу сохраняются в файл

## Важно

- Для удаления сообщений боту нужны права администратора
- Команды администратора доступны только ID, указанным в `.env`
- Свой ID можно узнать командой `/help`

## Псевдонимы названий групп

В списке групп бот показывает название чата так, как оно задано в Telegram. Чтобы вместо него
показывать своё имя, заполните файл `group_titles.json`:

```json
{
  "-1002391432309": "Моя основная группа",
  "-1002061288009": "Вторая группа"
}
```

ID группы видно в разделе «Информация о группе». Файл читается при каждом показе списка, поэтому
правки подхватываются без перезапуска бота. Если псевдонима нет, показывается название из Telegram.

## Команды управления группой

- `/mute @имя_пользователя 1 день` - мут на срок (минуты/часы/дни/недели/месяцы/годы; без срока — навсегда)
- `/unmute @имя_пользователя` - снять мут (участнику придёт сообщение в личку)
- `/ban @имя_пользователя 1 день` - бан на срок (по умолчанию навсегда)
- `/unban @имя_пользователя` - снять бан (бот напишет в личку и пришлёт ссылку на чат)
- `/jy` и `/jc` - то же самое, но срок в секундах

## Должности

- `/admin_add @имя_пользователя 1-5` - выдать должность: 5 — Владелец, 4 — Администратор,
  3 — Ст.Модератор, 2 — Модератор, 1 — Мл.Модератор
- `/admin_remove @имя_пользователя 0-5` - понизить до указанной должности, 0 — снять совсем
- `/admins` - список руководства: создатель бота и все должности
- Выдавать должности может создатель бота (`CREATOR_USERNAME` в `.env`), админы из `ADMIN_IDS` и Владельцы

Во всех этих командах вместо `@ника` можно ответить на сообщение участника и указать только срок.
Данные хранятся в `ranks.json`.

## Развлечения

Команды действуют на того, кому вы ответили:

- `/убить`, `/поцеловать`, `/обнять`, `/трахнуть`, `/выебать` — ответная реакция с эмодзи
- `/шипперим` — случайная пара из участников чата
- `/кто_я` — своя карточка: статус в чате, должность, первое появление, последний актив, активность
- `/кто_ты` (ответом на сообщение) — карточка участника

Латинские псевдонимы: `/kill`, `/kiss`, `/hug`, `/fuck`, `/hardfuck`, `/ship`, `/whoami`, `/whois`.
Статистика участников хранится в `users.json`.

## Добавление бота в группу

Кнопки «Добавить в группу» и «Добавить в канал» показывают инструкцию прямо в чате: ссылки вида
`t.me` кастомные клиенты (DropGram/DropGram) не открывают и выдают ошибку
«This link is for Telegram's official network». Добавлять бота нужно вручную:
Управление группой → Участники → Добавить участника → `@имя_бота`, затем выдать права администратора.


## Деплой на Render

1. Залей эту папку в GitHub-репозиторий.
2. На https://render.com → **New + → Blueprint** → выбери репозиторий (подхватится `render.yaml`).
3. **Environment → Environment Variables** → добавь `BOT_TOKEN` со значением токена.
4. Нажми **Deploy**. Готово — бот работает 24/7, порт подставляется сам.
